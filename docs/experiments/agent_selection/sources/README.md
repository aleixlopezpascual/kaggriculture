# Agent Selection Tournament Sources

> **Important Caveats on Execution & Licensing**
> * **Execution Security:** Agent runners execute candidate Python in-process via `exec`, with NO sandbox. You must only run reviewed and trusted source snapshots.
> * **Source Authorship & Licensing:** The captured Kaggle sources bundled in this directory may contain submitter-authored modifications alongside inherited, third-party, or open-source components described in their own notices. The bundled copies are strictly hash-pinned captures of the linked public outputs; do not assume all code was originally authored by the listed Kaggle notebook author. We retain Apache/NOTICE attribution detail where present, without making broader unsupported licensing claims.

This directory contains the portable source code bundles for the public Kaggle agents tested in the phase-one selection tournament. The historical selection experiment can be fully reproduced using `candidates.json` from the parent directory, which now targets these portable source files via relative paths.
